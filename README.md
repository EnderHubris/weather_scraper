# Weather Scraper
## Run
```console
git clone https://github.com/EnderHubris/weather_scraper.git
cd weather_scraper
python3 -m venv .
source bin/activate
pip install -r requirements.txt
python3 scrapcli.py
```
### REMARK: Playwright Package
Upon the first execution of using playwright due to a fresh pip installation, you will be asked to run the following to download new browsers for it to use
```console
playwright install
```
